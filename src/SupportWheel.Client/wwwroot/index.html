Snurra Hjulet – Slumpa vinnare online

Skriv in namn, alternativ eller vad som helst – snurra på hjulet och låt slumpen avgöra! Perfekt för att välja mat, aktiviteter, namn eller lottdragningar.

Så fungerar det

  1. Skriv in dina alternativ (ett per rad)
  2. Välj hur många som ska dras
  3. Tryck "Snurra!" och se vem som vinner

Funktioner

  • Obegränsat antal alternativ
  • Dela resultat via länk
  • Spara hjul för återanvändning
  • Party-läge med ljud och effekter
  • API för utvecklare

Gratis, ingen registrering krävs. Fungerar på mobil, surfplatta och dator.
